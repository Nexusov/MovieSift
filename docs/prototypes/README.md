# Workspace proposal

Open `workspace-review.html` directly in a browser. It is self-contained and does not read media, access the network, or run jobs.

This accepted proposal guides the workspace implementation:

- Reversible × actions exclude tracks from the result, while muted cards stay in their original positions and offer Restore.
- Copy and Replace are visible beside the destination; replacement still needs temporary space and explicit consent.
- Review emphasizes removed tracks and collapses retained tracks behind a category summary.
- Adjacent help opens on hover or keyboard focus and closes with Escape.

The inspection screen demonstrates elapsed time and explicitly unavailable remaining time, not a predicted countdown. Fixture names and paths are fictional. The standalone HTML is a design artifact, not native desktop acceptance.

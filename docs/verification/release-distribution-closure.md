Its release-source cross-build helper follows moving MXE inputs. That historical closure is not asserted resolved. Each complete source package is hash-checked, and its original PKGBUILD must match the actual binary BUILDINFO. ## Obligations and remaining decisions

Complete material accounting is not a universal legal conclusion. [GPLv2 section 3](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html) requires the covered corresponding source, including the relevant modules/interfaces and scripts controlling compilation and installation; it does not demand proof of a bit-identical rebuild or every incidental historical compiler input. [Qt's LGPL guidance](https://doc.qt.io/qt-6/lgpl.html) distinguishes the applicable source/relink requirements and a suitable shared-library mechanism. [Boost's license](https://www.boost.org/LICENSE_1_0.txt), [zlib's terms](https://zlib.net/zlib_license.html) and the [GCC Runtime Library Exception](https://www.gnu.org/licenses/gcc-exception-3.1.html) must be applied to the actual components instead of imposing a blanket full-source rule on all permissive/runtime files.

The remaining concrete distribution gates are:

1. **Windows replacement source delivery:** the same-version source-built pair has its own matched covered-source/patch/build materials instead of inheriting the old binaries' unknown closure. Preserve those exact materials and notices and actually deliver them alongside the matching public binaries. A private local bundle or expiring CI worker artifact does not itself accomplish public source delivery. No upstream message has been sent.
2. **Linux QtCore material is collected:** complete QtBase includes configure/CMake/build internals, Linux specifications, bundled third-party notices and GPL2/LGPL3/GPL3 texts. A scan of this exact archive found 724 Core C/C++/header files with the explicit alternative license expression and 161 BSD3 documentation snippets. No additional missing Core source, patch, compiler-history or relink-object artifact was identified. The separate shared library has no runtime replacement lock. If the LGPL3 alternative is used instead, its suitable shared-library mechanism is an alternative to supplying relink objects, not an additional requirement. Preserve the applicable notices and actually deliver the collected source/build materials with a future public release. The omitted VirtualKeyboard and other unused Qt modules are no longer candidate payloads. See the [pinned Core header](https://github.com/qt/qtbase/blob/v6.6.1/src/corelib/global/qglobal.h) and the license texts inside the collected source.
3. **Final notices and distribution method:** retain the final collected closure's actual terms/attributions and make required covered source/build materials available alongside a future release. Compiler-history and permissive-source preferences remain separate provenance questions. Selecting MIT for original TrackTrim code does not complete public covered-source delivery.

No public portable archive is uploaded by this change. Final inventory reports cover the actual new package, including sources/notices, without using historical file counts as expected constants. Mandatory MKV/MP4 packaged execution, relocation and the no-SDK/no-external-media Linux container remain required independently of this material work.
